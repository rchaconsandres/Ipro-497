# App content

All the words shown in the app live in this folder, so you can edit them without
touching any screen code.

| File | Shown on | Owner |
|---|---|---|
| `lessons.ts` | Learn tab | Hannah |
| `checklists.ts` | Checklist tab | Lyla |
| `articles.ts` | Articles tab | Akshitha, Saloni |
| `community.ts` | Community tab | Tony |

## How to edit

- Change only the text between the quotes `'like this'`.
- If your text contains an apostrophe, write it as `\'` (for example `'don\'t'`),
  or wrap the whole text in double quotes instead: `"don't"`.
- To add an item, copy an existing `{ ... },` block (including the comma) and
  change its text.
- Leave the field names (`title:`, `objective:` and so on) as they are.

## Rules

- **Clinician review:** Lesson, checklist, and article wording must be reviewed
  by the clinical team before patients use the app.
- **Made-up data only:** Community posts and names are invented. Never add real
  patient information.
